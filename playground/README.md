# Playground

Small early Lisp experiments live here: shape and identity puzzles, miniature factories, process/continuity
sketches, seminar fragments, and a few pieces that are as much prose as program. Filenames carry their dates
because this is a notebook shelf, not a release lane.

Try reading or running:

- `2026-07-10-shape-equal.lisp` and `2026-07-13-shape-equal.lisp` as two moments in the same identity question;
- `2026-07-10-sbcl-condition-of-type-identity-crisis.lisp` for a Common Lisp condition-system miniature;
- `2026-07-13-two-factories.lisp` for generative sameness across factories;
- `2026-07-11-mneme-shards.md` for the conceptual fragments surrounding the runnable toys.

Individual `.lisp` files may be invoked with `sbcl --script FILE` after reading their assumptions. There is
no aggregate playground floor and no promise that every historical sketch belongs to the current load order.

**Not here:** governing specifications, adopted APIs, or release evidence. A clever toy can generate a later
law; it cannot retroactively acquire that law's standing.
