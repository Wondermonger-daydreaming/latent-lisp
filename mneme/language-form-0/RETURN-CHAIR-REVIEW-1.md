## A. Export surface and forgeability

**86 → 97** external symbols (+11 dual-identity and content-digest readers).

The census is at `EXPORT-CENSUS.md`, generated by `PUBLIC-SURFACE-AUDIT.lisp`,
which **fails** if any symbol lacks a declared caller / minting power /
disposition, or if any declared disposition names a symbol that is not exported.
*Every export is accounted for* is therefore a tooth, not a promise.

Nothing was pruned. Every phase struct uses `(:conc-name %…)`, so no
`DEFSTRUCT`-generated accessor is public — the public readers are hand-written
wrappers that copy. **No symbol survives merely because a `DEFSTRUCT` generated
it.**

### The twelve-point walk: 10 refused, 2 possible

Run from a package that uses only `#:cl` and the **external** symbols of
`LISP-PLUS-FORM0`. A check reads the audit's own source and requires that it
contains no double-colon reference into the audited package — an audit that
reaches past its own boundary proves nothing about that boundary.

| # | attempt | result |
|---|---|---|
| 1–3 | construct `VALIDATED-FORM` / validation receipt / realization receipt | **refused** — no such constructor is external |
| 4 | forge or alter predecessor identities | **refused** — no writer exists |

| 9 | mutate internal collections through exported readers | **refused** — clobbering a reader's result does not reach the environment |
| 10 | replace a descriptor while preserving the environment identity | **now refused** — `:environment-content-drift` (was **possible** before this round) |
| 11 | call an internal handler through an exported accessor | **refused** — no public handler accessor exists at all |
| 12 | create a phase object whose invariants were never earned | **refused** — `:not-validated` |

### The two that are possible — and the one that was live

- **L-1** — `MAKE-OPERATOR-DESCRIPTOR` accepts any host function. An outsider can
  install anything behind an innocent segmented identifier.
- **L-2** — two environments agreeing on identity, version, grammar, resource
  policy **and every operator's identity / arity / result-species** are
  indistinguishable to every gate `REALIZE-FORM` owns.

**Before this round the demonstration was not theoretical.** A form validated
under the honest desk **realized under a swapped desk and returned `"forged"`**:

```
probe 3 — the two environments' identities are EQUAL-DATUM?  T
probe 3 — validated under HONEST, realized under SWAPPED:    ACCEPTED
         result = "forged"   handler that ran = :SWAPPED-HANDLER-RAN
```

All five drift gates passed while an attacker's handler ran, because every gate
compared **names and versions** and none compared **contents**.

**Repaired.** A `form-environment-content-digest` commits to the whole declared
surface — version, grammar, resource policy, every operator's
identity/arity/result-species, every hole's identity/species. Validation binds
it; realization re-checks it. Attempt 10 now refuses with
`:environment-content-drift`.

**Not repairable by a digest.** Handler behaviour itself: a host closure has no
canonical content. `T-HANDLER-SUBSTITUTION` asserts that realization is **NOT**
refused and that the substituted handler ran — a tooth that documents a limit
rather than claiming a protection.

### The contradiction, reported rather than decided

Per the instruction *"if an external program can supply arbitrary handler
functions to a form environment, stop and report the contradiction"* — it can,
and this is that report. The fork is in `CHAIR-REVIEW-RESPONSE-1.md` §A.3 and is
**undecided**:

| option | buys | costs |
|---|---|---|
| **(a) trusted-program model** (status quo + explicit statement) | nothing to build; the honest description of what is true | no promise against a hostile installer |
| **(b) declared handler identity** bound into the digest | converts a silent substitution into a lie on the record | still self-declared; adds a required argument |
| **(c) package-controlled installation** | a real enforcement boundary | the layer stops being usable by an ordinary program without a second mechanism |

The closure's *"incapable of granting authority"* now carries an erratum: that
was true of **the four operators this layer installs** and false as a general
claim. **The guarantee is form↔environment, never program↔program.**

## B. Dual identity — it was absent

`validated-form-identity` returned `(%hex instantiated-datum)` — the *syntax*,
not the validation. **The previous return printed one value at four stages
because at three of them it genuinely was one value.**

### Implemented now, with phase tags

| identity | domain | commits to |
|---|---|---|
| subject-form | `%hex` of the canonical datum | the syntax alone — **stable** across phases |
| proposed | `phase/proposed` | subject + grammar identity/version |
| binding-environment | `phase/binding-environment` | the exact (hole, value) pairs |
| instantiated | `phase/instantiated` | proposal **phase** identity + binding identity + resulting subject |
| validated | `phase/validated` | instantiation **phase** identity + grammar id/v + environment id/v + **content digest** + resolved descriptor identities + resource policy + subject |
| validation receipt | `phase/validation-receipt` | the same components under a **distinct tag** |
| realization receipt | `phase/realization-receipt` | validated **phase** identity + realized subject + operators + result |

### Two things building it taught, both worth more than the feature

**(i) The abbreviation lied twice before it told the truth.** A 16-character
*head* slice collapses every identity (shared CD/0 magic); a 16-character *tail*
slice also collapses them (shared trailing components). The display now prints
**length** beside the slice, and `check-abbreviations-discriminate` asserts the
printed abbreviations are pairwise distinct whenever the full identities are.
*That diagnostic had already lied once — to the chair, in the previous return.*

**(ii) Phase identities grow with depth:** 440 → 1040 → 3772 → 10684 → 22476
characters, because each phase embeds its predecessor's full identity **as a
string**. Finite and correct for Form /0's four phases; **quadratic and
unacceptable** for any frontier that chains transformations. The fix is a
fixed-length digest, which this project cannot take casually having criticised
"pedagogical, not cryptographic" digests elsewhere. **Recorded as Form /1
friction, not fixed under time pressure.**
