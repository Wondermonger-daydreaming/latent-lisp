# NON-PRODUCTION FEASIBILITY PROBE — Surface Account /0 — the ID SEQUENCES.
# not a package, not an API, not loadable as part of any system.
# ==========================================================================
#
# THE EXACT ORDERED CHECK-ID / ANCHOR SEQUENCE OF EVERY SECTION, DECLARED HERE
# AS DATA.  The verifier does not guess these and does not derive them from the
# artifact under test: it is TOLD them, exactly as it is told the profile and
# the tip.
#
# WHY A SEQUENCE AND NOT A COUNT.  Counts collapse.  Two checks that swap
# places, a check that fires twice while another never fires, a whole provider
# half replaced by a repetition of the other — all of these preserve the count
# and all of them are a different transcript.  The ordered ID stream does not
# collapse: it names WHICH assertion ran, and WHERE.
#
# FORMAT — one ID per line, in order:
#
#     <profile>:<SECTION>  <ID>
#
# The IDs come from two declared sources, both in verify-grammar.txt:
#
#   - the `  CHECK-ID <ID>` line the probe emits immediately after every
#     `  [PASS] <label>` verdict line (probe-prelude.lisp, PROBE-CHECK).  The
#     ID is written at the assertion s call site in the probe sources; it is a
#     name, not a position;
#   - the ANCHOR productions, which turn a structural line into an ID by the
#     declared id-ERE and the declared normalization (non-alphanumeric runs to
#     one dash, upper-cased) — CASE-01, END-CASE-01, CONTROL-1, C6-PROVIDER-S1,
#     C6-S1-STEP-1, END-C6-PROVIDER-S1, C7-S2-EXACT-SHAPE, FRESHNESS-T1,
#     END-FRESHNESS-T1, STOP-CASE-11, and so on.
#
# PROVENANCE, STATED RATHER THAN IMPLIED.  These sequences were authored at R2
# from ONE clean run of the probe at the R2 tip and were then read against the
# probe sources check by check — the R2 commission s minimum bindings (matrix
# cases 01-14, C6-PROVIDER S1 and S2, C6-S1-STEP-1..9, C6-S2-STEP-1..9, the
# matching END-C6-PROVIDER anchors, the exact C7/S2 species/category/phase/code
# assertion, and the freshness T1/T2/T3 anchors) are each present below and
# were checked by name.  A sequence has to be authored from something; what
# makes it external is that it is FROZEN HERE, in the sources, and the artifact
# under test can no longer move it.  It is not a claim that the probe was
# verified against an independent oracle.
