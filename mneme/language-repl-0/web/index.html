      What this workbench does not show

      The server does not supply these, so the page does not invent them:

      • steps used (only the step budget is known)
      • per-form values of a multi-form submission: only the last form's result is shown
      • positions inside a form: an error cites its submission's location and the failing expression, not the line inside a closure's body where that expression was defined
      • what happened to a request whose answer never arrived: the page says "outcome unknown" and offers a read-only refresh
      • types beyond kind
      • provenance or evidence fields of any kind
      • timings per form: elapsed is for the whole submission
      • prelude and primitive names (Names lists user bindings only)
      • any server-side history: there is none; this page's history is local and lost on reload
