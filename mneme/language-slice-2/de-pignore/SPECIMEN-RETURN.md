## What the specimen established

An explicitly elected evidentiary requirement about one exact Slice /2 premise
**can** remain identifiable and open across unrelated intervening derivations,
and **can** be reconciled by an admissible witness under the retained rule —
with **no new language layer**, **no mutable status**, and **no `:OPEN` →
`:CLOSED` transition**. Openness is derived by folding a caller-supplied ordered
history, the shape borrowed from Kernel /0's unresolved-effect
(`uncertain-effect.lisp:52`, `folds.lisp:421`) without importing a single
Kernel /0 record type.

**52 checks produced, 0 failed** (Review 1: 40; original: 25). The count is
derived from the verdict list the run accumulates; the runner reports only what it executed and asserts no project
adoption, freeze or audit standing.

## What it did NOT establish

- **No persistence, replay, or cross-image resolution.** Process Journal /0 is
  adopted as a specification, but no journal store is wired into Kernel /0's
  in-memory core. The fold consumes a list the caller supplies. There is no store.
- **No global exactly-once discharge.** `:ALREADY-RECONCILED` is enforceable only
  relative to the history supplied. A caller omitting a prior receipt can obtain
  another reconciliation. Demonstrated by a check, **not solved with a registry**.
- **No authority, truth, standing, or minted basis** of any kind.
- **No proof of which Slice /2 wrapper produced the earlier receipt** — the
  substrate does not record it. Concordance rests on anatomy: premise-index
  bounds, retained premise pattern, and the complete contract snapshot.
- **No partial reconciliation.** Slice /2 admission for one premise is
  structurally all-or-nothing; no partial case was invented to populate the
  residue field.
- **No external corroboration.** These greens are same-family self-consistency,
  written by the same model line that wrote the machinery under test.

## Why a public layer is not warranted

A `slice2-receipt` already remembers the premise, the `:missing` disposition and
the governing contract **by value**. What the specimen genuinely adds reduces to
three things: **an election**, **a fold**, and **a live anchor**. That is a real
addition — an author's undertaking is a fact no existing object held — and it is
a thin one with exactly **one** tenant. A public layer would mint a ministry for
a single inhabitant.

Keeping it application-local costs nothing and leaves the door open: if a second
genuine inhabitant appears, the specimen is already written and the question
reopens with evidence rather than enthusiasm.
