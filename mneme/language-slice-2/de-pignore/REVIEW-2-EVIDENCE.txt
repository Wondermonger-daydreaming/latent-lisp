Two further observations the probe surfaced, neither anticipated:

  (a) STRUCTURE SHARING BETWEEN OBJECTS.  The receipt's target-occurrence and the

      mutates both, so the fold's EQUAL comparison still passed after tampering

      tampering because both sides of its comparison moved together.  A tooth
      that only asks "does a valid receipt still close?" cannot see this.

  (b) THE TAMPERING BROKE A LATER RECONCILIATION.  After the D1 mutations, a
      fresh TRY-RECONCILE-OBLIGATION on the same obligation refused
      :CONTRACT-DRIFT — because the caller's mutation of the contract-snapshot
      VIEW had corrupted the obligation's own retained rule.  This masked D2 on
      the first attempt and had to be re-run against a fresh obligation.  It is
      also the sharpest demonstration of severity available: a caller holding
      only a READER can invalidate an obligation it does not own.

D3 — TRANSCRIPT COUNT DISCREPANCY               CAUSE FOUND — MINE
----------------------------------------------------------------------
Observed in the Review-1 relay artifact:

    footer count               40 checks produced / 0 failed
    rendered verdict lines     39
    rendered numbers           1..27, 29..40
    missing                    28
    contract-drift tooth       ABSENT from the transcript (grep count 0)

CAUSE — determined, not guessed.  SPECIMEN-RUN.txt is NOT a tracked artifact; it
was generated during relay assembly by piping the raw SBCL output through

    grep -vE '^;|^ *$|STYLE-WARNING|caught|^This is SBCL|...'

The token `caught` was in that exclusion list in order to strip SBCL's
"caught 1 STYLE-WARNING condition" lines.  Verdict 28's label reads:

    "§5  a live contract with the SAME id but DIFFERENT accepted clauses is
     caught as :CONTRACT-DRIFT (the old NC14 label was false)"

It contains the word "caught".  The filter therefore deleted a DATA line because
it resembled NOISE.

NOT a source/run mismatch.  NOT a stale transcript.  The run itself produced 40
verdicts; the ARTIFACT rendered 39, and its footer then disagreed with its own
body.

This is the fourth instance of the day's defect inside this specimen's own tooling:
a filter matching on SURFACE TEXT removed a verdict because the verdict's prose
resembled the noise the filter was built to strip.  The transcript is an
instrument, and this one misreported the run it was documenting.
